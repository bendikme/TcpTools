## TcpTools 26.11.2

### Fixed

- **Received text is on screen at once.** The text views of the client, the server and the relay are a new
  control that draws only the visible lines instead of the Windows edit box, which laid its whole text out
  again and again as it grew. A megabyte of received data now shows in about 0.2 s (it took 3.5 s, and
  up to 9 s in the relay); 4 MB of text in about 0.4 s.

### Changed

- The receive text views have a white background like the hex view, wrap at the window's edge by
  character (the edit box wrapped by word), and show a tab as one blank.
- They follow new data only while the end is in view: scroll back to read and the view stays put.
- Select with the mouse (drag, Shift+click, double-click a word) or Ctrl+A; copy with Ctrl+C or the
  right-click menu.

### Notes

- The file is still not code-signed (no certificate is configured): Windows SmartScreen may ask before
  the first start.
